## HTML and CSS
- HTML: Hyper Text Markup Language (The builder)
- CSS: Cascading Style Sheet (The arttist)
- Javascript (The wizard)
- HTML and CSS are two languages that work together to create everything that you see when you look at something on the web.
- HTML is the raw data that a webpage is built out of. All the text, links, cards, lists, and buttons are created in HTML.
- CSS is what adds style to those plain elements.
- HTML puts information on a webpage, and CSS positions that information, gives it color, changes the font, and makes it look great!
- Techincally they are **NOT** programming languages because they just present data, and are not used to implement any logic
- Javascript on the other is a programming language because it’s used to make webpages do things such as popup error messages, auto complete etc. 
- All these are components of the Frontend development stack
- The browser converts/translate these 3 languages into the webpage that we actually see

## Elements and Tags
- HTML defines the content and the structure of the webpage. That is done with the help of elements and tags.

| Feature | HTML Tag | HTML Element |
| :--- | :--- | :--- |
| **Example** | `<p>` (opening) or `</p>` (closing). | `<p>Hello world!<p>`. |

### Tags
- HTML tags are essential building blocks that define the structure and content of a webpage
- Opening tags tell the browser that this is the start of an HTML element. hey are comprised of a keyword enclosed in angle brackets `<>`
- Closing tags tell the browser where an element ends. They are almost the same as opening tags; the only difference is that they have a forward slash before the keyword. `</p>`
- Using the correct tags can have a big impact on two aspects of your sites: how they are ranked in search engines; and how accessible they are to users who rely on assistive technologies, like screen readers, to use the internet.
- - [List of tags](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements)

### Elements
- Elements = Tags + content within the tag
- You can think of elements as containers for content. The opening and closing tags tell the browser what content the element contains. The browser can then use that information to determine how it should interpret and format the content.
- Some HTML elements do not have a closing tag. These elements just have a single tag, like: `<br> or <img>`. They are known as void elements because they are void of any content. 
- When working in a Word or google doc, you can do things like changing the size of the text, changing the font, defining if it is a title, paragraph, link etc. 
- And based on how we strcuture it (what headings are defined, what is the title, etc) it starts building a document structure.
- But when using HTML there are no menus to achieve this directly hence we use the tags to achieve the same result allowing the browser to correctly interpret the and translate the document based on the structure defined and display it. 
- e.g: browser is not capable of reading the line breaks you have entered in the code file or the code editor, it will interpret everything as continous text because it has not been explicitly instructed to handle them as new lines via elements such as paragraph or line break etc.

## HTML Boilerplate
- The basic structure of all HTML documents is the same which needs to present before we start building something.
- The file extension for html is `.html`
- We should always name the HTML file that will contain the homepage of our website `index.html`. This is because web servers will by default look for an index.html page when users land on our websites – and not having one will cause big problems.
- (Code stored in `html-boilerplate` folder for reference)

1. The DOCTYPE 
- Every HTML page starts with a doctype declaration. The doctype’s purpose is to tell the browser what version of HTML it should use to render the document. The latest version of HTML is HTML5
    - `<!DOCTYPE html>`

2. HTML Element
- After we declare the doctype, we need to provide an <html> element. This is the root element of the document,  meaning that every other element in the document will be a descendant of it.
- For some tags, we can define some addon details - which are called as `attributes` and these are specific the tags and the content contained within them
    - `<html lang=en></html>
    - Here `lang` attribute defined the language of the text within that element

3. Head Element
- The `<head>` element is where we put important meta-information about our webpages, and stuff required for our webpages to render correctly in the browser.
- **Inside the `<head>`, we should <u>not</u> use any element that displays content on the webpage.**
- It should always be the first element under the opening `<html>` tag
```
<!DOCTYPE html>

<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>Document</title>
    </head>
</html>
```
- We should always have the `<meta>` tag with the charset encoding of the webpage in the `<head>`. Setting the encoding is very important because it ensures that the webpage will display special symbols and characters from different languages correctly in the browser.
- Another element we should always include in the head of an HTML document is the `<title>` element. It is used to give webpages a human-readable title, which is displayed in our webpage’s browser tab
- If we didn’t include a `<title>` element, the webpage’s title would default to its file name (index.html).

4. Body Element
- The final element needed to complete the HTML boilerplate is the `<body>` element. This is where all the content that will be displayed to users will go - the text, images, lists, links, and so on.

## Working with Text
1. Paragraphs
- If we want to create paragraphs in HTML, we need to use the paragraph element, which will add a new line after each of our paragraphs. A paragraph element is defined by wrapping text content with a <p> tag.

2. Headings
- they are displayed larger and bolder than other text to signify that they are headings. There are 6 different levels of headings starting from `<h1>` to `<h6>`. 
- The number within a heading tag represents that heading’s level with f1 being the largest and most important and h6 being tiniest
- Using the correct level of heading is important as levels provide a hierarchy to the content.

3. Strong
- It makes text **bold**. It also semantically marks text as important (this affects tools, like screen readers, that users with visual impairments).
- Some tutorial also state the use of `<b> ... </b>` which also makes the text bold, but only **visually** and does not lay any actual importance on it for screen readers etc.

4. Em
- It is used to make the text *italic*. It also semantically places emphasis on the text, which again may affect things like screen readers.
- Some tutorial also state the use of `<i> ... </i>` which also makes the text italic, but only **visually** and does not lay any actual emphasis on it for screen readers etc.

5. Nesting and indentation
- When we nest elements within other elements, we create a parent and child relationship between them. The nested elements are the children and the element they are nested within is the parent.
```
<body>
    <p>Lorem ipsum <em>dolor sit</em> amet, consectetur adipiscing elit.</p>
</body>
```
- e.g: body element is the parent and the paragraph is the child
- Elements at the same level of nesting are considered to be siblings.
- We use indentation to make the level of nesting clear and readable for ourselves and other developers

6. Comments
- HTML comments are not visible to the browser; they allow us to comment on our code for better context
- In order to write an HTML comment, we just enclose the comment with `<!--` and `-->` tags
```
<!-- I am an html comment -->
```

## Lists

### Unordered lists
- If you want to have a list of items where the order doesn’t matter, like a shopping list of items that can be bought in any order, then you can use an unordered list.
- Unordered lists are created using the `<ul>` element, and each item within the list is created using the list item element `<li>`.
```
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

### Ordered lists
- If you instead want to create a list of items where the order does matter, like step-by-step instructions for a recipe, or your top 10 favorite TV shows, then you can use an ordered list.
- Ordered lists are created using the `<ol>` element. Each individual item in them is again created using the list item element `<li>`
```
<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>
```

## Links
- Note: Folder `links-and-images` contain the code relevant to this section
- Absolute links: Links to pages on other websites on the internet are called absolute links.
- Relative links: Links to other pages within our own website are called relative links. It includes the file path to the other page (for the path reference - By adding `./` you are specifying to your code that it should start looking for the file/directory relative to the current directory - wherever index.html is stored)

1. Anchor elements
- To create a link in HTML, we use the anchor element defined by `<a>` tag. To define where the link should redirect to we need to use the `href` attribute of the tag. You can link to videos, pdf files, images, other html docs etc.
- By default, any text wrapped with an anchor tag without an href attribute will look like plain text. 
- If the href attribute is present, the browser will give the text a blue color and underline it to signify it is a link
- Simply using the href attribute, opens the link in the same tab. For the link to open in new tab by default we use the `target` attribute. It specifies where the linked resource will be opened.
    - If it is not present, then, by default, it will take on the _self value which opens the link in the current tab.
    - To open the link in a new tab or window (depends on browser settings) you can set it to _blank
- There is another attribute `rel` that defines the relation between the current and linked document
    - `noopener`: Prevents the new tab from accessing the original page, which would have opened the possibility of phishing attacks like tabnabbing.
    - `noreferrer`: The same as noopener but also prevents certain details about the original page from being passed to the new page

## Images
- To display an image in HTML we use the `<img>` element. Unlike the other elements we have encountered, the `<img>` element is a void element (no closing tag present).
- Instead of wrapping content with an opening and closing tag, it embeds an image into the page using a src attribute (can be external or internal reference)

1. Alt attribute
- Besides the src attribute, every image element should also have an alt (alternative text) attribute. The alt attribute is used to describe an image. It will be used in place of the image if it cannot be loaded.

2. Image size attributes
- While not strictly required, specifying height and width attributes in image tags helps the browser layout the page without causing the page to jump and flash.
- It is a good habit to always specify these attributes on every image, even when the image is the correct size or you are using CSS to modify it.
