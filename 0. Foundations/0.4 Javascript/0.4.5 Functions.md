- Functions: Imagine taking one of your scripts and bundling it into a little package that you could use over and over again without having to rewrite or change the code. That’s the power of functions
```
function favoriteAnimal(animal) {
    return animal + " is my favorite animal!"
}

const message = favoriteAnimal('Goat')
console.log(message)
// OR console.log(favoriteAnimal('Goat'))
```

- The functions can also be directly defined in the html doc as well under the `script` tag
```
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Function Example</title>
</head>
<body>

    <!-- 1. The Script Tag containing the function -->
    <script>
        // Declaring the function
        function sayHello(name) {
            console.log("Hello, " + name + "!");
        }

        // Calling the function inside the script tag
        sayHello("Alex"); 
    </script>

</body>
</html>
```
