# Data Types and Conditionals

## Data Types
- We can put any type in a variable.
    - For example, a variable can at one moment be a string and then store a number:
        ```
        // no error
        let message = "hello";
        message = 123456;
        ```
- There are eight basic data types in JavaScript:
    1. Number: 
        - The number type represents both integer and floating point numbers. ` let n=123; or let n=12.324`
        - There are many operations for numbers, e.g. multiplication *, division /, addition +, subtraction -, and so on.
        - Besides regular numbers, there are so-called “special numeric values” which also belong to this data type:
            - ***Infinity:*** represents the mathematical Infinity ∞. `alert( 1 / 0 ); // Infinity OR alert( Infinity );`
            - ***NaN:*** represents a computational error. It is a result of an incorrect or an undefined mathematical operation `alert( "not a number" / 2 );`
                - NaN is sticky. Any further mathematical operation on NaN returns NaN `alert( NaN + 1 );`
                    - *there’s only one exception to that: NaN \*\* 0 is 1*
            - ***- Infinity***
    2. BigInt
        - In JavaScript, the “number” type cannot safely represent integer values *larger than (2<sup>53</sup>-1)* (that’s `9007199254740991`), or less than -(2<sup>53</sup>-1) for negatives.
        - BigInt type was recently added to the language to represent integers of arbitrary length
        - A BigInt value is created by appending n to the end of an integer: `const bigInt = 1234567890123456789012345678901234567890n;`
    3. String
        - A string in JavaScript must be surrounded by quotes. `let str = "Hello";`
        - In JavaScript, there are 3 types of quotes:
            - Double quotes: "Hello".
            - Single quotes: 'Hello'.
            -   Backticks: \`Hello\`.
        - Double and single quotes are “simple” quotes. There’s practically no difference between them in JavaScript.
        - Backticks are “extended functionality” quotes. They allow us to embed variables and expressions into a string by wrapping them in `${…}` (similar to fstrings in python)
        ```
        let name = "John";
        alert(`Hello ${name}!`);
        alert( `the result is ${1 + 2}` ); // the result is 3
        ```
    4. Boolean
        - The boolean type has only two values: true and false.
        ```
        let nameFieldChecked = true; // yes, name field is checked
        let ageFieldChecked = false; // no, age field is not checked
        let isGreater = 4 > 1;
        ```
    5. The "null" value
        - The special null value does not belong to any of the types described above.
        - It forms a separate type of its own which contains only the null value: `let age = null;`
        - It’s just a special value which represents “nothing”, “empty” or “value unknown”.
    6. The "undefined" value
        - The meaning of undefined is “value is not assigned”. If a variable is declared, but not assigned, then its value is undefined: `let age; alert(age); `
        - Technically, it is possible to explicitly assign undefined to a variable: `let age = undefined;`
    7. Objects and Symbol
        - All other types are called “primitive” because their values can contain only a single thing (be it a string or a number or whatever).
        - `objects` are used to store collections of data and more complex entities (similar to dictionaries).
            ```
            // Creating an object using object literal syntax
            const user = {
              name: "Alex",
              age: 28,
              isAdmin: true,
              // A method inside an object
              greet: function() {
                console.log("Hello!");
              }
            };
            ```
            - You can access properties or call methods from an object using two different notations
                - Dot Notation: user.name (Best for standard property names)
                - Bracket Notation: user\["name"\] (Required if the property name has spaces or is stored in a dynamic variable)
            - Objects in JavaScript are mutable, meaning you can freely update their contents after they are created.
                - Add/Update: user.age = 29; or user.location = "New York";
                - Delete: delete user.isAdmin;
        - The `symbol` type is used to create unique identifiers for objects. Every time you call Symbol(), it generates a completely unique value, even if you give it the exact same description string.
            ```
            const sym1 = Symbol("id");
            const sym2 = Symbol("id");
            console.log(sym1 === sym2); // false
            ```
    8. The typeof operator
        - The typeof operator returns the type of the operand.
        ```
        typeof undefined // "undefined"
        typeof 0 // "number"
        typeof 10n // "bigint"
        typeof true // "boolean"
        ```

## Conditionals
- essence of programming is teaching the computer how to make decisions to do more involved things. Conditionals are how we do that.

### Comparisons:
- Greater/less than: `a > b, a < b`.
- Greater/less than or equals: `a >= b, a <= b`
- Equals: `a == b`
- Not equals: `a != b`
- Comparisons return `boolean` results. They can be used to compare not only numbers but also strings *strings are compared letter-by-letter.* 
- When comparing values of different types, JavaScript converts the values to equivalent numbers before comparing
- A strict equality operator `===` checks the equality without type conversion.

### If ... else
```
if (condition) {
  /* code to run if condition is true */
} 
else {
  /* run some other code instead */
}
```
- You can have multiple conditions as well:
```
if () {
    /* code A */
}
else if (condition) {
    /* code B */
}
else if (condition) {
    /* code C */
}
else {
    /* code D */
}
```
- It is perfectly OK to put one `if...else` statement inside another one.

### Logical Operators
- AND, OR and NOT
- `&&` — AND; allows you to chain together two or more expressions so that all of them have to individually evaluate to true for the whole expression to return true.
- `||` — OR; allows you to chain together two or more expressions so that one or more of them have to individually evaluate to true for the whole expression to return true.
- `!`: NOT; Inverts Booleans: It turns true into false, and false into true `let isLogged = true; let checkAccess = !isLogged; // Evaluates to false`

### Switch
- For cases where you just want to set a variable to a certain choice of value or print out a particular statement depending on a condition, the `if...else` syntax can be a bit cumbersome, especially if you've got a large number of choices. In such a case, switch statements are your friend 
```
switch (expression) {
  case choice1:
    // run this code
    break;

  case choice2:
    // run this code instead
    break;

  // include as many cases as you like

  default:
    // actually, just run this code
    break;
}
```

### Ternary operator
- The ternary or conditional operator is a small bit of syntax that tests a condition and returns one value/expression if it is true, and another if it is false
- `condition ? if true run this code : else run this code instead`
```
const greeting = isBirthday
  ? "Happy birthday Mrs. Smith — we hope you have a great day!"
  : "Good morning Mrs. Smith.";
```

### for loop
- for loop in JS is similar to how we use for loop in C++
```
for (let i = 1; i <= answer; i++)
```
