- Node.js (or just “Node”) is a JavaScript runtime environment that allows you to run JavaScript outside of your web browser. 
- **We’re going to install it using nvm (Node Version Manager), because it makes it easy to change Node versions and upgrade Node.**
- **There is another tool called npm that we will later use to install the various libraries and tools used in JavaScript environments.**. 

- We first need to install nvm so that we can install and manage our Node installations easily. 
    - [Linux](https://github.com/TheOdinProject/curriculum/tree/main/foundations/javascript_basics/installation_guides/linux.md)
    - [macOS](https://github.com/TheOdinProject/curriculum/tree/main/foundations/javascript_basics/installation_guides/macos.md)
- Now that we have nvm installed, we can use it to install Node.
    - `nvm install --lts`
    - This will install the most recent stable version of Node in “long-term support” (LTS)
- We need to tell nvm which version of Node to use when we run the node command.
    - `nvm use --lts`
- Now when you run `node -v`, you should see `vXX.xx.x`
- Installing Node also installs npm alongside it. 

- Finally, we’ll implement a setting introduced in npm v11.10.0 that delays the installation of newly released dependencies.
    - `npm config set min-release-age=3`
    - This setting will prevent npm from installing dependencies that were released less than three days ago

- For convenience, Node provides a REPL which is an interactive console that lets you run and edit your JavaScript code right in your terminal.
